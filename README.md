# Dockerized pipreqs


## Что делает проект
`pipreqs` — это консольная утилита для Python. Она сканирует исходный код проекта, 
находит все импорты и автоматически генерирует файл `requirements.txt`. Это альтернатива `pip freeze`, которая не тянет лишние зависимости.

## Какой вариант задания выбран и почему
Выбран **Вариант 1 («Просто работает»)**. Проект представляет 
собой консольную утилиту без веб-интерфейса. Контейнер собирает образ, 
после чего преподаватель может запустить его для анализа любого проекта, примонтировав папку.
