# DevOps2 - Dockerized pyVCT (Cardiac Tissue Model)

## Что делает проект
Это контейнеризированная версия научного проекта pyVCT — модели виртуальной сердечной ткани на основе Cellular Potts Model. Проект симулирует поведение клеток сердечной ткани и выводит результаты в консоль.

## Какой вариант задания выбран и почему
Выбран **Вариант 1 («Просто работает»)**.

Проект представляет собой консольное приложение на Python/Cython. При запуске контейнера выполняется Jupyter ноутбук `example.ipynb`, сконвертированный в Python-скрипт. Результаты выводятся в терминал.
