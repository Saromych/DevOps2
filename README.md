# DevOps2 - Dockerized pipreqs

## Что делает проект
`pipreqs` — это консольная утилита для Python, которая сканирует исходный код проекта, анализирует все импорты и автоматически генерирует файл `requirements.txt`. В отличие от `pip freeze`, она включает только те пакеты, которые реально используются в проекте.

## Какой вариант задания выбран и почему
Выбран **Вариант 1 («Просто работает»)**.

Проект `pipreqs` — это консольная утилита без графического интерфейса. Она идеально подходит под критерии Варианта 1: запускается одной командой, выводит результат в терминал, не требует проброса портов или сохранения данных.
